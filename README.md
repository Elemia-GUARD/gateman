# gateman
Building and developing the main firewall solution of a network.

The program/service is consisting of three microservices:-

1- Packet Capture
2- Verdict Machine
3- Logging Machine
4- Control Panel

The Verdict Machine is subdivided into two applications:-

1- Decision Maker
2- Session Generator

All the diagrams of development are existing in the directories of the repository itself.

They are connected together using some system sockets or internet sockets.

The sockets are the best choice because of offering many interfaces like what should be developed in User Experience department with GUARD Insight team.

They should be developed and upgraded every time a new round begins.
